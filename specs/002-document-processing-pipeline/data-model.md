# Data Model: Document Processing Pipeline

All tables below are scoped (directly or transitively) to a `project_id` referencing
001-core-foundation's `projects` table, with RLS enforcing `owner_id = auth.uid()` via that
relationship.

## Entity: `documents`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid` | PK, default `gen_random_uuid()` | |
| `project_id` | `uuid` | NOT NULL, FK → `projects.id` (`ON DELETE CASCADE`) | Isolation boundary (FR-019) |
| `filename` | `text` | NOT NULL | Original filename |
| `file_type` | `text` | NOT NULL | Detected MIME/format |
| `storage_path` | `text` | NOT NULL | Path in Supabase Storage, namespaced by `project_id` |
| `status` | `text` | NOT NULL, CHECK IN (`uploaded`,`queued`,`partitioning`,`chunking`,`summarizing`,`vectorizing`,`stored`,`failed`) | Denormalized latest status for fast reads; source of truth is `processing_status_events` |
| `failure_reason` | `text` | NULL | Set only when `status = 'failed'` (FR-005) |
| `uploaded_at` | `timestamptz` | NOT NULL, default `now()` | |
| `updated_at` | `timestamptz` | NOT NULL, default `now()` | Updated on every status change |

**Relationships**: Belongs to exactly one `projects` row. Has many `processing_status_events`,
`elements`, `chunks`.

**Validation rules**: `file_type` must be in the supported-format allowlist (FR-002); rejected
uploads never create a `documents` row.

**RLS policy**: Access requires `EXISTS (SELECT 1 FROM projects WHERE projects.id =
documents.project_id AND projects.owner_id = auth.uid())`.

---

## Entity: `processing_status_events`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid` | PK, default `gen_random_uuid()` | |
| `document_id` | `uuid` | NOT NULL, FK → `documents.id` (`ON DELETE CASCADE`) | |
| `stage` | `text` | NOT NULL, CHECK IN (same 8 values as `documents.status`) | |
| `occurred_at` | `timestamptz` | NOT NULL, default `now()` | |
| `reason` | `text` | NULL | Populated only for `stage = 'failed'` |

**Relationships**: Belongs to exactly one `documents` row (transitively one project).

**Behavior**: Append-only. A document's current status = the row with the latest
`occurred_at` for that `document_id`. Used both to drive SSE stream updates (FR-007) and to
reconstruct status on reload/reconnect (FR-008, FR-023).

**RLS policy**: Transitive via `documents.project_id` → `projects.owner_id = auth.uid()`.

---

## Entity: `elements`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid` | PK, default `gen_random_uuid()` | |
| `document_id` | `uuid` | NOT NULL, FK → `documents.id` (`ON DELETE CASCADE`) | |
| `element_type` | `text` | NOT NULL, CHECK IN (`text`,`title`,`table`,`image`,`other`) | Matches Unstructured's typed categories (FR-009) |
| `page_number` | `int` | NULL | Source page, when applicable |
| `sequence_index` | `int` | NOT NULL | Order within the document, for structural reconstruction |
| `raw_text` | `text` | NULL | Populated for text/title elements |
| `created_at` | `timestamptz` | NOT NULL, default `now()` | |

**Relationships**: Belongs to exactly one `documents` row. Has zero or one `asset_references`
row (for table/image elements) and zero or one `summaries` row. Contributes to one or more
`chunks`.

**RLS policy**: Transitive via `documents.project_id`.

---

## Entity: `asset_references`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid` | PK, default `gen_random_uuid()` | |
| `element_id` | `uuid` | NOT NULL, UNIQUE, FK → `elements.id` (`ON DELETE CASCADE`) | One-to-one with a table/image element (FR-011) |
| `storage_path` | `text` | NOT NULL | Path to the original table/image asset in Supabase Storage, namespaced by `project_id` |
| `created_at` | `timestamptz` | NOT NULL, default `now()` | |

**Relationships**: Belongs to exactly one `elements` row (table/image only).

**RLS policy**: Transitive via `elements.document_id → documents.project_id`.

---

## Entity: `summaries`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid` | PK, default `gen_random_uuid()` | |
| `element_id` | `uuid` | NOT NULL, UNIQUE, FK → `elements.id` (`ON DELETE CASCADE`) | One-to-one (FR-010) |
| `summary_text` | `text` | NOT NULL | Generated by Gemini multimodal summarization |
| `generated_at` | `timestamptz` | NOT NULL, default `now()` | |

**Relationships**: Belongs to exactly one `elements` row (table/image only).

**RLS policy**: Transitive via `elements.document_id → documents.project_id`.

---

## Entity: `chunks`

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | `uuid` | PK, default `gen_random_uuid()` | |
| `document_id` | `uuid` | NOT NULL, FK → `documents.id` (`ON DELETE CASCADE`) | Denormalized for direct query without joining through elements (FR-014) |
| `element_id` | `uuid` | NOT NULL, FK → `elements.id` (`ON DELETE CASCADE`) | |
| `page_content` | `text` | NOT NULL | Raw text (text/title) or summary text (table/image); matches LangChain `Document.page_content` |
| `element_type` | `text` | NOT NULL | Denormalized copy of `elements.element_type` for query convenience |
| `page_number` | `int` | NULL | Denormalized copy of `elements.page_number` |
| `asset_reference_id` | `uuid` | NULL, FK → `asset_references.id` | Present only for table/image-derived chunks (FR-015) |
| `processed_at` | `timestamptz` | NOT NULL, default `now()` | |
| `embedding` | `vector(N)` | NOT NULL | `pgvector` column; dimension `N` fixed by chosen embedding model |

**Relationships**: Belongs to exactly one `documents` row and one `elements` row (transitively
one project).

**Validation rules**: Every row MUST have `document_id`, `element_type`, `page_number` (when
applicable), and `processed_at` populated — this is the enforced minimum for
source-traceability (FR-014, SC-006).

**RLS policy**: Transitive via `document_id → documents.project_id → projects.owner_id =
auth.uid()`.

---

## Cross-Cutting Rules

- All six tables above are additive to the schema from 001-core-foundation; none replace or
  modify existing `projects`/`conversations`/`messages` tables.
- Every table's RLS policy composes with 001-core-foundation's existing `projects` RLS policy
  rather than duplicating ownership logic — a single source of truth for "who owns this
  project" is preserved.
- `documents.status` is a denormalized convenience column; `processing_status_events` remains
  the authoritative, append-only audit trail (constitution Principle VIII: auditability).
